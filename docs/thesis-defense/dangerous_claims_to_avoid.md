# Dangerous Claims to Avoid
- Dangerous claim: `The AI is fully accurate.`
  Safer version: The AI is grounded and assistive, but teacher and student users should still review outputs critically because AI responses are not perfect.
- Dangerous claim: `The system fully replaces teacher intervention.`
  Safer version: The system supports teachers by surfacing learning gaps and assisting remedial planning, but teacher judgment remains central.
- Dangerous claim: `The platform is ready for full production deployment.`
  Safer version: The platform is best described as a technically mature prototype that is strongest for controlled pilot preparation.
- Dangerous claim: `The AI never hallucinates.`
  Safer version: The system uses grounding and policy controls to reduce hallucination risk, but it does not claim zero-error AI behavior.
- Dangerous claim: `The system supports all subjects completely.`
  Safer version: The system is designed for broad secondary-school use, but the safest defense scope is the current implemented and demonstrated coverage.
- Dangerous claim: `The platform is already proven effective.`
  Safer version: The current study demonstrates implementation feasibility and workflow integration; larger-scale outcome validation remains future work.
- Dangerous claim: `Mobile fully matches the web app.`
  Safer version: Mobile access is implemented, but feature parity differs by role and workflow.
- Dangerous claim: `The threshold of 74% is universally correct.`
  Safer version: The current system uses 74% as its configurable mastery cutoff within project scope and it should still be validated against school policy.
- Dangerous claim: `The AI can grade everything safely.`
  Safer version: The AI assists with support and generation workflows, while official academic records and final grading remain outside direct AI authority.
- Dangerous claim: `The school can deploy this with no special maintenance.`
  Safer version: A controlled pilot is a more honest deployment claim, especially for the AI-enabled stack.
- Dangerous claim: `Our charts already prove long-term learning improvement.`
  Safer version: The analytics and reports demonstrate workflow visibility, but not full long-term educational impact by themselves.
- Dangerous claim: `The system is fully compliant with every privacy requirement.`
  Safer version: The system implements concrete security and privacy-aware controls, but institutional compliance still depends on policy, governance, and rollout review.
