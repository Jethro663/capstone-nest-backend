Purpose: concise inventory of modules, exported components, types, and features in the `test-mobile` Expo app. Use this as the basis for Figma design prompts (features, screens, components, and flows to improve).

Overview - Primary Features
- Authentication & session (login flow, auth provider)
- Navigation: app navigator, bottom tabs, role-based routing
- Student dashboard / role workspace
- Assessments: list, take, history, results, detail
- Lessons / Modules / Content viewing and detail pages
- LXP (learning experience platform) and AI Tutor flows
- Profile, Progress, Performance, Transcript
- Announcements, School events, Reports
- API layer (services + client, error handling, hooks)
- Theming and UI primitives (tokens, colors, shared UI)
- Local mock data and mappers for dev/demo

Structure & Modules (grouped by folder)

src/screens/
- AiTutorScreen.tsx: AI tutor experience screen (exports `AiTutorScreen` component)
- AnnouncementsScreen.tsx: announcements list (component)
- AssessmentDetailScreen.tsx: assessment detail view (component)
- AssessmentHistoryScreen.tsx: past attempts (component)
- AssessmentResultsScreen.tsx: results display (component)
- AssessmentTakeScreen.tsx: assessment-taking UI (component)
- AssessmentsScreen.tsx: assessments index (component)
- ClassDetailScreen.tsx: classroom detail (component)
- CoursesScreen.tsx: courses listing (component)
- DashboardScreen.tsx: main student dashboard (component)
- JaScreen.tsx: 'Just Ask' / JA feature screen (component)
- LessonDetailScreen.tsx: content/lesson detail (component)
- LessonsScreen.tsx: lessons listing (component)
- LoginScreen.tsx: authentication UI (exports `LoginScreen`)
- LxpScreen.tsx: LXP entry & listings (exports `LxpScreen`)
- ModuleDetailScreen.tsx: module detail (component)
- PerformanceScreen.tsx: performance summary (exports `PerformanceScreen`)
- ProfileScreen.tsx: user profile (exports `ProfileScreen`)
- ProgressScreen.tsx: progress summary (exports `ProgressScreen`)
- RoleWorkspaceScreen.tsx: role-based workspace (exports `RoleWorkspaceScreen`)
- screen-flow.ts: helpers and route inventories (exports many helper functions such as `resolveInitialLxpClassId`, `buildTutorAnswerPayload`, `computeProfileReadiness`, plus route inventory constants)
- SubjectLessonsScreen.tsx: lessons per subject (exports `SubjectLessonsScreen`)
- TeacherUnsupportedScreen.tsx: placeholder for teacher UX (exports `TeacherUnsupportedScreen`)
- TranscriptScreen.tsx: transcript view (exports `TranscriptScreen`)
- several `__tests__` files under screens/ for unit tests

src/navigation/
- AppNavigator.tsx: top-level navigator wiring (exports navigator components)
- role-resolver.ts: role resolution logic for route selection
- student-route-manifest.ts: route manifests and name collections (exports `studentRouteManifest`, `studentTabRouteNames`, `studentStackRouteNames`, etc.)
- types.ts: navigation param types (RootStackParamList, MainTabParamList, AuthStackParamList)

src/providers/
- AppProviders.tsx: app-level providers composition
- AuthProvider.tsx: authentication context and hooks
- ErrorModalProvider.tsx: error modal provider and hook (`useErrorModal`)

src/api/
- client.ts: API client setup
- config.ts: API configuration values
- http.ts: HTTP helper and wrapper around fetch/axios
- hooks.ts: API hooks (react-query hooks wrappers)
- queryClient.ts: react-query client configuration
- errors.ts: API error mapping and presentation helpers
- storage.ts: local storage helpers (async storage wrapper)

src/api/services/
- auth.ts: login / session endpoints
- profile.ts: profile read/update endpoints
- performance.ts: performance-related endpoints
- modules.ts, lessons.ts, assessments.ts, announcements.ts, lxp.ts, classes.ts, dashboard.ts, reports.ts, school-events.ts: domain-specific service wrappers used by hooks and screens
- ai.ts: AI-related service endpoints used by `AiTutorScreen` and AI flows

src/components/
- ui/BottomTabBar.tsx: bottom tab bar customization
- ui/primitives.tsx: shared primitives (buttons, text, layout helpers)

src/bootstrap/
- AppRoot.tsx: app entry component for Expo (mounts navigator and providers)

src/data/
- mockData.ts: mock datasets (subjects, lessons, assessments, lxpRecommendations, aiMentorMessages, userProfile)
- mappers.ts: mapping utilities between API payloads and UI types
- types.ts: domain data shape definitions for mock data

src/theme/
- tokens.ts: theme tokens (colors, gradients, shadow, radii) and small helpers (`hexToRgba`)

src/types/
- many `*.ts` type definition files describing domain models and API envelopes (assessment.ts, api.ts, auth.ts, ai.ts, announcement.ts, lesson.ts, lxp.ts, module.ts, performance.ts, profile.ts, report.ts, user.ts, etc.)

Tests
- `__tests__` folders under `src/api` and `src/screens` contain unit tests for API services and navigation/flow logic.
